# Autenticación

Responsabilidad prevista: iniciar/cerrar sesión y exponer identidad del usuario y agencia autorizada. Reutilizar las credenciales de la web mediante la futura API de firmas.

Se incorporarán `domain`, `data`, `presentation` y `di` al aprobar el contrato. No usar los tokens ni el rol de RRHH como autorización de firmas. La política de sesión y persistencia está pendiente.

Referencia: `docs/ARQUITECTURA.md` y `docs/PROPUESTA_API.md` en la raíz del repositorio.
